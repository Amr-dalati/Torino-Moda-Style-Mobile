# Torino Moda Style - Flutter Mobile App

A Flutter mobile application for Torino Moda Style, designed as a customer-facing e-commerce app for women’s shoes, bags, and accessories.

The app is built to work with a Laravel backend API and provides a complete shopping flow including product browsing, product details, cart management, checkout, customer authentication, and online order processing.

## Project Purpose

This project was developed to support an e-commerce business by allowing customers to browse available products, add items to cart, and place orders through a mobile application.

## Key Features

- Customer authentication
- Product listing
- Product details
- Product search
- Cart management
- Checkout flow
- Delivery area selection
- Order creation
- API integration with Laravel backend
- Responsive mobile UI
- Clean Flutter project structure

## Tech Stack

- Flutter
- Dart
- REST API Integration
- Laravel Backend
- MySQL Database
- Sanctum Authentication
- Git & GitHub

## Backend Integration

The mobile app is designed to connect with a Laravel backend that handles:

- Products
- Categories
- Customers
- Authentication
- Cart
- Checkout
- Orders
- Payments
- Delivery regions and areas

## Project Architecture

The app follows a structured Flutter approach with separated layers for:

- Screens
- Widgets
- Models
- Services
- API calls
- State management
